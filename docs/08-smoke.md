## 备注（执行中发现的、不属于失败项的东西）

- **导入坏包没验成，是测试手段的问题，不是应用的问题**：这台机的系统文件选择器（DocumentsUI）「最近」里只列被系统索引过的文件，`adb push` 进去的文件**不会**出现在这里——后来做数据迁移时才看清：应用自己导出的 zip 会排在「最近」最上面，`adb push` 的不会。下一轮把坏包放进应用自己的导出目录再选，或改用应用内能直接读到的路径。
- **文案表里 371 那条改了个不存在的东西**：`copy-review` 把「请检查网络后重试」记成了用量抽屉的刷新失败，但抽屉刷新失败是静默的（显示 `--`），界面上并不会出现这句话；真机上看到的是 `ErrorKind.retryHint` 的原文「请检查网络后重试」。这一行应当撤回，或在表里改成「无落点」。
- **执行中撞到的整屏变黑（P-036）已复判，不再挡发版**：2026-11-22 六轮排查确认它只在 adb 级操作下复现（切系统默认输入法 + 注入按键毫秒级连发），正常操作——点输入框、键盘弹起、来回切中英输入法、打字、收键盘——实测不触发，因此降为 P2 观察项。机制、证据与取舍见 `polish-log.md` 的 P-036 与 `docs/03-handoff.md` 的决策 72；本清单里输入法相关的几项据此不必为它重走。
